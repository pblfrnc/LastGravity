# LastGravity para VS Code

Agentes de IA que planejam, editam, rodam comandos e verificam o próprio trabalho — com Claude, Gemini, OpenAI, OpenRouter ou Ollama (grátis, local).

- **LastGravity: Abrir central de controle** — o Editor e o Gerenciador de agentes num painel.
- **LastGravity: Nova tarefa** (⌘⌥L) — cria um agente.
- Clique direito numa seleção → **Pedir ao agente sobre a seleção**.

As chaves de API ficam só no seu computador (~/.lastgravity).
